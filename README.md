## Для чего это

Если вы хотите обсудить договор, найти письмо или разобраться в таблице, удобно делать это в **обычном чате ChatGPT, со своей квотой сообщений**, без перехода в агентный режим Work или Codex ради чтения файлов.

Strigov Local MCP подключает к чату выбранные папки на вашем компьютере. После однократной настройки можно спрашивать о документах, не прикрепляя их вручную к каждому разговору. Например: «Найди договор с “Альфой”, покажи срок оплаты и укажи страницу».

Разговор в Chat подчиняется лимитам выбранной чат-модели. У Work и Codex общие лимиты работы; конкретные квоты и правила учёта зависят от тарифа и рабочего пространства. Приложение не добавляет квоту и не снимает ограничения ChatGPT. [Подробнее о Work и Codex](https://learn.chatgpt.com/docs/pricing).

## Возможности

| | Что можно делать |
|---|---|
| 📁 **Подключать свои папки** | Выбирать несколько папок, давать им понятные имена и отключать доступ через меню приложения. |
| 🔎 **Находить нужное** | Искать файлы по названию и текст внутри документов. Читать большие документы частями. |
| 📄 **Разбирать документы** | Читать PDF, Word, Excel, сохранённые письма и вложения. Просить указать страницу, лист или строку источника. |
| 🖼️ **Смотреть изображения и сканы** | Открывать изображения и отдельные страницы PDF, увеличивать нужный фрагмент. |
| 📦 **Заглядывать в архивы** | Просматривать ZIP и читать файлы внутри без ручной распаковки. |
| 👁️ **Сохранять оригиналы** | Приложение умеет читать и искать; изменять и удалять ваши файлы через него нельзя. |

Всё это доступно в [версии 2.2.0](https://github.com/strigov/GPT-MCP-filesystem/releases/tag/v2.2.0) — текущем предварительном выпуске от 29 октября 2026 года.

### Какие файлы поддерживаются

| Файлы | Что получает ChatGPT |
|---|---|
| **PDF** | Текст с номерами страниц; для сканов — просмотр отдельной страницы. |
| **Word: DOCX, DOCM** | Основной текст, таблицы, комментарии и исправления. |
| **Excel: XLSX, XLSM, XLS** | Сохранённые значения ячеек с указанием листов и строк. Формулы не пересчитываются. |
| **Письма: EML, MSG** | Отправитель, тема, текст и доступные вложения. |
| **ZIP** | Список файлов и чтение поддерживаемых документов внутри, в том числе во вложенных архивах. |
| **PNG, JPEG, GIF, WebP, TIFF, BMP** | Изображение или выбранный фрагмент; у TIFF можно выбрать страницу. |
| **Текст, Markdown, CSV, исходный код** | Текст в кодировке UTF-8. |

Поиск по содержимому работает с текстом документов. Встроенного распознавания сканов (OCR) нет: страницу можно показать ChatGPT, но поиск по папке не найдёт слова на изображении без текстового слоя. Внутри ZIP и вложений нужно искать отдельно, указав конкретный файл.

<details>
<summary>Если формат не поддерживается</summary>

- HEIC/HEIF сохраните как JPEG или PNG.
- DOC, PPT/PPTX, ODT/ODS и RTF сохраните в подходящий поддерживаемый формат, например PDF.
- RAR и 7z распакуйте или сохраните как ZIP.
- Документы Office с шифрованием не поддерживаются; пароль для PDF ввести нельзя.
- Сложное оформление Word и Excel передаётся не полностью: например, графики Excel и колонтитулы Word не читаются. Для визуальной проверки сохраните документ в PDF.

</details>

## Установка

### Что понадобится

- **Mac с чипом Apple (M1 или новее), macOS 13+** либо **Windows 10/11 x64**. Готовых сборок для Intel Mac и Windows ARM64 в этом релизе нет.
- **ChatGPT с возможностью добавить свой MCP-сервер через Tunnel** и доступ к разделу туннелей в OpenAI Platform. MCP здесь — способ дать чату доступ к вашим файлам; программировать ничего не нужно.
- Интернет и включённый компьютер во время работы с файлами.

Перед установкой проверьте, что вам доступны [туннели OpenAI Platform](https://platform.openai.com/settings/organization/tunnels) и добавление своего подключения в [ChatGPT Plugins](https://chatgpt.com/plugins). В рабочем аккаунте доступ может предоставлять администратор. Установщик сам эти разрешения не выдаёт.

Дополнительные программы и инструменты разработчика устанавливать не требуется.

### macOS

1. Откройте меню ** → Об этом Mac**. В поле «Чип» должен быть указан Apple M1, M2 или более новый чип Apple.
2. [Скачайте установщик для Mac](https://github.com/strigov/GPT-MCP-filesystem/releases/download/v2.2.0/Strigov-Local-MCP-2.2.0-macos-arm64.dmg). Файл называется `Strigov-Local-MCP-2.2.0-macos-arm64.dmg`; обычно он попадает в «Загрузки».
3. Дважды нажмите на скачанный файл. В открывшемся окне запустите **Install Strigov Local MCP.app**.
4. Нажмите **«Установить»**. Приложение появится в папке `Applications` внутри вашей домашней папки и запустится автоматически.
5. Найдите **значок серверной стойки в верхней строке меню**. Отдельного большого окна у приложения нет. Теперь переходите к [подключению ChatGPT](#подключение-к-chatgpt).

<details>
<summary><b>macOS не даёт открыть установщик — что делать</b></summary>

У текущего выпуска нет нотариализации Apple. Если macOS сообщает, что не может проверить разработчика, закройте сообщение и откройте **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть** для этого установщика.

Если это не помогло, можно снять отметку о загрузке из интернета только с установщика:

1. В открытом образе DMG скопируйте **Install Strigov Local MCP.app** в папку **«Загрузки»**. Дальше работаем с этой копией, а не с файлом внутри образа.
2. Нажмите **⌘ Space**, введите **Терминал** (или `Terminal`) и откройте его.
3. Вставьте команду целиком и нажмите **Enter**:

   ```sh
   xattr -dr com.apple.quarantine "$HOME/Downloads/Install Strigov Local MCP.app"
   ```

4. Откройте «Загрузки» в Finder и дважды нажмите **Install Strigov Local MCP.app**, затем **«Установить»**.

Команда рассчитана на указанное имя и папку «Загрузки». Используйте её только для установщика, скачанного по ссылке из этого репозитория. Она снимает карантин с этой копии приложения; общесистемную защиту macOS отключать не нужно. Если появилось `No such file`, проверьте, что скопировали приложение в «Загрузки» и не переименовали его.

</details>

### Windows

1. [Скачайте архив для Windows](https://github.com/strigov/GPT-MCP-filesystem/releases/download/v2.2.0/Strigov-Local-MCP-2.2.0-windows-x64.zip). Файл называется `Strigov-Local-MCP-2.2.0-windows-x64.zip`.
2. Откройте «Загрузки», нажмите на архив правой кнопкой и выберите **«Извлечь все…» → «Извлечь»**.
3. В распакованной папке запустите **`local-files-installer.exe`**. Рядом должна оставаться папка `payload`: не переносите установщик отдельно и не запускайте его прямо из ZIP.
4. Нажмите **«Установить»**. Права администратора не нужны.
5. Найдите **значок серверной стойки возле часов**. Если его не видно, нажмите стрелку **˄**, которая показывает скрытые значки. Теперь переходите к [подключению ChatGPT](#подключение-к-chatgpt).

<summary><b>Windows показывает «Система Windows защитила ваш компьютер»</b></summary>

У текущего выпуска нет подписи издателя. Если вы скачали архив по ссылке из этого репозитория, нажмите **«Подробнее» → «Выполнить в любом случае»**. На рабочем компьютере запуск может быть ограничен правилами организации — в таком случае обратитесь к администратору.

</details>

## Подключение к ChatGPT

Это однократная настройка. **Туннель** — соединение между приложением на вашем компьютере и OpenAI. Для него понадобятся **ID** (номер подключения) и **ключ** (секрет для доступа).

### 1. Выберите папки

Нажмите значок приложения → **«Подключённые папки» → «Добавить папку…»**. Выберите папку с документами. Повторите для остальных папок. При желании задайте понятное имя через **«Изменить прозвище…»**, например «Договоры» или «Учёба».

### 2. Создайте соединение в OpenAI

В меню приложения откройте **«Подключение ChatGPT» → «Создать туннель в OpenAI Platform…»**. Создайте туннель в своей организации и свяжите его с тем рабочим пространством ChatGPT, где будете читать файлы. Скопируйте его **Tunnel ID**.

Затем выберите **«Получить runtime API key…»** в том же меню и создайте ключ с правами **Tunnels Read + Use**. Ключ понадобится в следующем шаге; в разговор с ChatGPT его вставлять не нужно.

Если Platform пишет **Tunnels access required**, попросите администратора предоставить **Read + Manage** для создания туннеля и **Read + Use** для подключения. [Официальная инструкция OpenAI](https://developers.openai.com/api/docs/guides/secure-mcp-tunnels).

### 3. Введите данные в приложение

Выберите **«Подключение ChatGPT» → «Настроить или сменить подключение…»**. В первом окне вставьте Tunnel ID, в следующем — ключ. Проверьте показанный список папок и подтвердите подключение.

Приложение запустит соединение. Дождитесь подтверждения связи в меню: значок стойки должен перестать быть перечёркнутым. Ключ сохраняется в системном хранилище компьютера.

### 4. Добавьте подключение в ChatGPT

Откройте [ChatGPT Plugins](https://chatgpt.com/plugins) в браузере:

1. Нажмите **«+» → Add custom MCP server**.
2. Задайте имя, например **«Мои файлы»**.
3. В разделе **Connection** выберите **Tunnel**, затем созданный туннель или вставьте его ID.
4. Если есть поле **Authentication**, выберите **No authentication**: отдельного входа у этого приложения нет, доступ идёт через ваш туннель.
5. Прочитайте запрос на подключение, подтвердите его и нажмите **Create as a plugin**. Установите созданный плагин, если интерфейс предлагает этот шаг.

Названия пунктов могут зависеть от версии интерфейса. [Инструкция OpenAI по добавлению подключения](https://developers.openai.com/plugins/deploy/connect-chatgpt).

### 5. Задайте первый вопрос

Начните новый разговор в режиме **Chat**. Введите **`@`** и выберите **«Мои файлы»** (или своё имя подключения), затем отправьте:

> Покажи, какие папки тебе доступны через «Мои файлы».

Когда увидите свои папки, попробуйте:

> Найди в папке «Договоры» упоминания срока оплаты. Укажи файл и страницу.

> Прочитай комментарии и исправления в «Соглашение.docx». Что ещё нужно согласовать?

> Посмотри лист «Расходы» в «Бюджет.xlsx» и объясни самые крупные статьи.

> Покажи, что лежит в «Архив.zip», и кратко перескажи нужный документ внутри.

> Открой третью страницу «Скан.pdf» и помоги разобрать, что на ней написано.

## Доступ к вашим файлам

**Вы сами выбираете, что доступно чату.** При первом запуске список папок пуст. Приложение не даёт инструментов изменения файлов, удаления или запуска команд. Некоторые служебные файлы, включая `.env`, `.ssh` и приватные ключи, дополнительно закрыты.

**Исходные файлы остаются на компьютере, а запрошенное содержимое передаётся OpenAI для ответа.** Это не полностью локальная обработка. Подключайте только те папки, содержимое которых готовы использовать в ChatGPT.

Управление доступом находится в меню приложения:

- **«Отключить доступ»** в меню папки — прекратить новые обращения к ней; файлы останутся на месте.
- **«Остановить»** — остановить соединение целиком.
- **«Отключить аккаунт…»** — остановить соединение и удалить сохранённый ключ. Список папок сохранится.

**«Закрыть значок» закрывает только меню приложения.** Фоновое соединение продолжает работать — для его остановки используйте «Остановить».

## Частые вопросы

<details>
<summary><b>Нужно ли держать компьютер включённым?</b></summary>

Да. Компьютер должен быть включён, подключён к интернету и не находиться в режиме сна; соединение приложения должно работать. После отключения компьютера ChatGPT не сможет прочитать новые данные из его папок.

</details>

<details>
<summary><b>ChatGPT не видит туннель или папки</b></summary>

Проверьте, что в меню приложения подтверждена связь, нужные папки добавлены, а туннель привязан к правильному рабочему пространству ChatGPT. На macOS также разрешите доступ к папке, если система об этом просит. После добавления папки попросите ChatGPT заново показать список доступных папок.

Если вы обновились с 2.1.x и новые возможности не появились, откройте подключение в ChatGPT Plugins, нажмите **Refresh** и начните новый разговор.

</details>

<details>
<summary><b>При просмотре PDF появился запрос «Allow file materialization?»</b></summary>

Некоторые страницы передаются как отдельный одностраничный PDF. Чтобы ChatGPT смог его открыть, выберите **Allow once** либо **Always allow for this chat**. Последнее разрешение действует только в текущем разговоре.

</details>

<details>
<summary><b>Как обновить приложение?</b></summary>

Скачайте установщик новой версии со страницы [релизов](https://github.com/strigov/GPT-MCP-filesystem/releases) и установите его тем же способом. Папки и подключение сохранятся; предыдущая версия приложения останется в резервной копии.

**На Windows перед обновлением** нажмите «Остановить», затем «Закрыть значок». После установки проверьте соединение и при необходимости нажмите «Запустить».

</details>

<details>
<summary><b>Как открыть приложение после перезагрузки?</b></summary>

На macOS значок запускается при входе в систему. На Windows соединение запускается в фоне, но сам значок нужно открыть отдельно: нажмите **Win + R**, вставьте `%LOCALAPPDATA%\Programs\Strigov Local MCP` и нажмите Enter. В открывшейся папке запустите `local-files.exe`.

</details>

<details>
<summary><b>Можно подключить второй компьютер?</b></summary>

Да. Установите приложение на второй компьютер и создайте для него отдельный туннель и отдельное подключение в ChatGPT. На каждом компьютере выбирается свой список папок.

</details>
