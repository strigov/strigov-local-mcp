Strigov Local MCP 2.2.1

УСТАНОВКА НА WINDOWS

1. Распакуйте ВЕСЬ архив в любую папку (Проводник: «Извлечь все»).
   Не запускайте установщик прямо из архива: рядом с ним должна лежать
   папка payload.
2. Запустите local-files-installer.exe и нажмите «Установить».
   Приложение будет установлено в
   %LOCALAPPDATA%\Programs\Strigov Local MCP
   и запустится в области уведомлений (значок серверной стойки).
Нужна Windows 10/11 x64. Права администратора не нужны.
Node.js, Docker, Rust, Python и PowerShell-скрипты на компьютере пользователя
не нужны.

Сборка не подписана сертификатом издателя. Windows SmartScreen может показать
предупреждение «Windows защитила ваш компьютер»: нажмите «Подробнее» →
«Выполнить в любом случае», если архив получен от доверенного источника.
Целостность файлов установщик проверяет сам по SHA-256 из install-manifest.json;
это не заменяет подпись издателя.

Установка из командной строки без запуска приложения:
  local-files-installer.exe --check
  local-files-installer.exe --install-to "C:\полный\путь" --no-launch

ПЕРВЫЙ ЗАПУСК

Дистрибутив не содержит аккаунтов, ключей, профилей или подключённых папок.
1. Нажмите значок серверной стойки → «Подключённые папки» → «Добавить папку».
2. В меню «Подключение ChatGPT» откройте создание туннеля в OpenAI Platform.
   Выберите собственную организацию и свяжите туннель с нужным workspace.
3. Создайте runtime API key с правами Tunnels Read + Use.
4. Выберите «Настроить или сменить подключение» и введите tunnel ID и ключ.
5. После установления связи добавьте custom MCP server в своём ChatGPT,
   выберите Tunnel и укажите этот туннель. Права workspace должны разрешать
   добавление и использование custom MCP servers.

Туннель запускается задачей планировщика «Local Files Tunnel» при входе
в Windows. Значок в трее отдельно в автозагрузку не добавляется — при
необходимости запустите local-files.exe из папки установки.

ДАННЫЕ И ОБНОВЛЕНИЯ

Настройки создаются только после запуска, отдельно от приложения:
%LOCALAPPDATA%\Local Files
Ключ хранится в Windows Credential Manager; в JSON, журналах и командной
строке его нет. Файлы доступны только для чтения и только в явно выбранных
папках.

Перед обновлением остановите туннель (значок → «Остановить») и закройте
значок («Закрыть значок»). Если приложение или
туннель ещё запущены, установщик откажет и ничего не изменит. После
обновления запустите приложение и туннель снова. При обновлении сохраняются
пользовательские настройки, а прежняя версия переносится в соседнюю папку
«Strigov Local MCP backup …». Установщик не перезаписывает чужие папки.

Secure MCP Tunnel предназначен для частных подключений. Распространение
этого desktop-приложения не является публикацией плагина в каталоге ChatGPT.

Официальная инструкция OpenAI:
https://developers.openai.com/api/docs/guides/secure-mcp-tunnels
