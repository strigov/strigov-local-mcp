# Проверка дистрибутива Local Files 2.1.0

Дата: 2026-10-12. Платформа проверки: macOS, Apple Silicon.

Артефакт: `dist/Local-Files-2.1.0-macos-arm64.dmg` (10,514,662 байт).
SHA-256: `18136dbdce9f645f9d677ea4c5fe6829d230e218cb10a1c2c71782d7847f0b58`.

## Что проверено

- Установка из смонтированного DMG в отдельный временный каталог, без запуска пользовательских служб.
- Первое создание настроек: ноль папок и отсутствие подключения. Переменные старой установки не добавляют корни.
- Повторная установка сохраняет настройки и прозвища; предыдущий bundle остаётся в резервной копии.
- В составе пакета нет folders.json, connection.json, tunnel.json, health.url, .env или абсолютного пути домашней папки разработчика. Упаковка использует явный список файлов.
- Подписи приложения и установщика проверены codesign --verify --strict --deep. Это проверка целостности ad-hoc подписи, не Developer ID и не нотариализация.
- cargo fmt --check, git diff --check и clippy с -D warnings прошли.
- 5 Rust unit-тестов и 18 Node/MCP-тестов прошли.
- Все 10 native MCP-тестов дополнительно прошли через worker приложения, установленного из финального DMG, с Seatbelt.
- Отдельный Rust integration-тест использовал фактический генератор профиля, упакованный tunnel-client и установленный worker. Пробелы и апострофы в пути обрабатываются; healthz/readyz отвечают; MCP-процесс запущен. Локальный тестовый endpoint не отвечает, поэтому connected остаётся false. Внешний аккаунт и реальные ключи не использовались.
- Существующий личный worker после проверок сообщил live=true, ready=true, connected=true. Новая служба и подключение в основной пользовательский профиль не устанавливались.

## Непроверенное и ограничения выпуска

- Реальная авторизация другого аккаунта/workspace не проверена: нужны его tunnel ID и runtime key, введённые владельцем в приложение.
- Автоматическая проверка кликов GUI не завершена: CUA вернул timeoutReached при получении тестового приложения; first-run процесс завершён, изолированные настройки остались в artifacts/distribution-gui-qa. Компиляция UI не заменяет проверку всех диалогов человеком.
- Нет Developer ID и нотариализации. На этой машине отсутствует подходящая signing identity. Публичная дистрибуция требует отдельного подписанного и нотариализованного релиза.
- Проверка на другой физической машине и macOS 13 не выполнялась. Deployment target — 13.0.
- Windows-исходники не подтверждены Windows-сборкой или запуском; Windows-установщик 2.1 не выпущен. Intel DMG не собран.
- Для каждой машины нужен отдельный туннель. Объединение нескольких машин за одним коннектором не реализовано.

Воспроизведение: `sh scripts/build-installer.sh`, затем `python3 scripts/verify-distribution.py dist/Local-Files-2.1.0-macos-arm64.dmg`. JSON-результат — рядом с DMG; пересборка меняет его хеш.
