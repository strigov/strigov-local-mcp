Strigov Local MCP 2.2.0

УСТАНОВКА НА macOS

Откройте «Install Strigov Local MCP.app», нажмите «Установить».
Приложение появится в ~/Applications и запустится в строке меню.
Нужна macOS 13 или новее. Сборка arm64 предназначена для Apple Silicon;
сборка x86_64 — для Intel. Используйте подходящий дистрибутив.
Node.js, Docker, Homebrew, Rust и Python на компьютере пользователя не нужны.

ПЕРВЫЙ ЗАПУСК

Дистрибутив не содержит аккаунтов, ключей, профилей или подключённых папок.
1. Нажмите значок серверной стойки → «Подключённые папки» → «Добавить папку».
2. В меню «Подключение ChatGPT» откройте создание туннеля в OpenAI Platform.
   Выберите собственную организацию и свяжите туннель с нужным workspace.
3. Создайте runtime API key с правами Tunnels Read + Use.
4. Выберите «Настроить или сменить подключение» и введите tunnel ID и ключ.
5. После установления связи добавьте custom MCP server в своём ChatGPT,
   выберите Tunnel и укажите этот туннель. Права workspace должны разрешать
   добавление и использование custom MCP servers.

Для другого компьютера создайте отдельный туннель и настройте его папки.
Чтобы сменить аккаунт/workspace на этом компьютере, настройте подключение
к соответствующему туннелю и проверьте список передаваемых папок.
Автоматического объединения папок нескольких компьютеров здесь нет.

Значок стойки: подтверждённая связь. Перечёркнутый: связи пока нет;
подробности показаны в меню. Закрытие значка не останавливает туннель.
«Отключить аккаунт» останавливает туннель и удаляет его сохранённый ключ.

ДАННЫЕ И ОБНОВЛЕНИЯ

Настройки создаются только после запуска, отдельно от приложения:
~/Library/Application Support/Local Files
Ключ хранится в macOS Keychain; в JSON, журналах и командной строке его нет.
Файлы доступны только для чтения и только в явно выбранных папках.
macOS может запросить разрешение на доступ к выбранным папкам.
При обновлении сохраняются пользовательские настройки и копия старого приложения.
Общий дистрибутив Local Files 2.1 обновляется до Strigov Local MCP с сохранением
подключения и папок. Прежнее имя каталога настроек оставлено для совместимости.
Старые персональные/разработческие установки не импортируются автоматически.

Эта локальная сборка подписана ad-hoc, без Developer ID и нотариализации Apple.
Публичный релиз для скачивания требует подписи и нотариализации издателя.
Secure MCP Tunnel предназначен для частных подключений. Распространение
этого desktop-приложения не является публикацией плагина в каталоге ChatGPT.

Официальная инструкция OpenAI:
https://developers.openai.com/api/docs/guides/secure-mcp-tunnels
